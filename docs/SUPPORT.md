# Support

Miskatonic Commons is a community open-source project. Please read this before
relying on anything here.

## Ways to get help

| Need | Where |
| --- | --- |
| Bug report or question | A [GitHub issue](https://github.com/Miskatonic-System/miskatonic-commons/issues) |
| Feature idea | A GitHub issue (feature request template) |
| Code or documentation fix | A pull request; see [CONTRIBUTING.md](../CONTRIBUTING.md) |
| Security problem | Private vulnerability reporting; see [SECURITY.md](../SECURITY.md) |

## What support means here

- **Community issue reporting.** Anyone may open an issue. Maintainers read
  them when they can.
- **Best-effort maintenance.** Fixes happen when maintainers have time. There
  is no schedule.
- **Security reports** are prioritized but still handled on a best-effort
  basis.
- **Commercial support does not exist.** No paid support, consulting or
  service plan is offered for Commons.

Nothing in Commons comes with a service-level agreement, a guaranteed
response, a warranty, or production certification. The software is provided
"AS IS" under the Apache License 2.0 (sections 7 and 8).

A package being listed in the index means only that it was cleared for public
distribution under its recorded scope. It is not a product endorsement or a
promise of maintenance.
